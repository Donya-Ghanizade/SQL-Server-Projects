# SQL Server Projects

A collection of SQL Server and T-SQL practice exercises developed as part of my learning journey in database development and data querying.

This repository contains practical exercises focused on writing SQL queries, working with relational databases, filtering and analyzing data, and applying common T-SQL concepts using Microsoft SQL Server.

## 📂 Project Structure

### 01 - SQL Server Basics

This section contains fundamental and intermediate SQL Server exercises using the **AdventureWorks** sample database.

The exercises focus on building a strong understanding of SQL query structure and working with data using different filtering, grouping, sorting, and conditional techniques.

**Topics covered:**

* SELECT statements
* WHERE conditions
* ORDER BY
* DISTINCT and column aliases
* Aggregate functions
* COUNT, SUM, MIN, MAX
* GROUP BY
* HAVING
* CASE expressions
* Conditional data classification
* CASE in ORDER BY
* TOP
* OFFSET / FETCH
* NULL handling
* IS NOT NULL
* Logical query processing order
* Basic query optimization concepts such as SARGable predicates

---

### 02 - TSQLV4 Query Exercises

This section contains practical query-solving exercises using the **TSQLV4** sample database.

The exercises focus on solving real-world-style data retrieval problems and applying different T-SQL techniques to filter, group, aggregate, and analyze data.

**Topics covered:**

* Date and time filtering
* Date range queries
* EOMONTH
* Pattern matching with LIKE
* GROUP BY and HAVING
* Aggregate functions
* SUM and AVG
* CASE expressions
* NULL handling
* ORDER BY
* WHERE vs HAVING
* Working with sales and employee data
* Writing queries based on specific business requirements

##  Tools

* Microsoft SQL Server
* SQL Server Management Studio (SSMS)
* T-SQL
* AdventureWorks
* TSQLV4

##  Purpose

The main purpose of this repository is to practice SQL Server and T-SQL through hands-on exercises and to build a stronger foundation in relational databases and data querying.

The exercises are organized into separate sections to make it easier to track different areas of SQL Server learning and progress.

##  Learning Focus

Through these exercises, I am practicing:

* Writing clear and structured SQL queries
* Retrieving and filtering data
* Aggregating and analyzing data
* Working with dates and text patterns
* Grouping and sorting query results
* Using conditional logic with CASE
* Understanding the difference between WHERE and HAVING
* Applying SQL concepts to practical data problems

##  Note

This repository is primarily intended for learning and practice. The exercises are based on sample databases and are organized as part of my ongoing SQL Server learning process.
